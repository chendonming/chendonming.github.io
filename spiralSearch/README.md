# 螺旋扩散搜索算法可视化

## 项目介绍

这是一个用于可视化展示螺旋扩散搜索算法的Web应用程序。该应用程序通过HTML5 Canvas绘制网格和搜索过程，直观地展示了螺旋搜索算法如何从起点开始，按照螺旋路径逐步扩散搜索目标点的过程。

## 功能特点

- 可视化展示螺旋搜索算法的搜索路径
- 实时显示搜索步数、已找到目标数量和搜索时间
- 支持重置搜索过程
- 自动检测目标点是否被找到
- 搜索完成后显示结果提示

## 使用方法

1. 打开`index.html`文件在浏览器中运行项目
2. 界面将显示一个20×20的网格，其中：
   - 绿色点：搜索起点（默认位置：10,10）
   - 红色点：目标点（默认位置：15,15和5,5）
   - 蓝色点：当前搜索位置
   - 灰色点：已访问过的位置
   - 橙色点：已找到的目标点
3. 点击"开始搜索"按钮启动搜索过程
4. 点击"重置"按钮可以重置搜索状态

## 算法原理

螺旋搜索算法是一种从中心点开始，按照螺旋路径向外扩散搜索的算法。其核心思想是：

1. 从起点开始，按照右→下→左→上的顺序移动
2. 每完成两次方向转换后，搜索步长增加1
3. 按照这种模式持续扩散，直到找到所有目标点或搜索完整个网格

该算法的实现使用了JavaScript生成器（Generator）函数，通过`yield`关键字逐步返回搜索路径上的每个点，实现了搜索过程的可视化。

## 技术实现

- 使用HTML5 Canvas进行网格和搜索过程的绘制
- 使用JavaScript生成器函数实现螺旋搜索算法
- 使用requestAnimationFrame实现平滑的动画效果
- 使用Set数据结构存储已访问点和已找到的目标点

## 自定义配置

在`script.js`文件中，可以修改以下参数来自定义搜索过程：

- `GRID_SIZE`：网格大小（默认为20×20）
- `CELL_SIZE`：单元格大小（默认为25像素）
- `DELAY`：动画延迟（默认为100毫秒）
- `startPoint`：起点坐标
- `targetPoints`：目标点坐标数组
